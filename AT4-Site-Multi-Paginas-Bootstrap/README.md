
# 🌐 AT4 - Desenvolvimento de Site Multi-Páginas com Bootstrap 5

## 📝 Descrição do Projeto

Este projeto foi desenvolvido na disciplina de **Desenvolvimento Front-End para Web**, do curso de **Análise e Desenvolvimento de Sistemas (ADS)** da Universidade Cidade de São Paulo (UNICID), no 2º semestre de 2026.

A atividade teve como proposta o desenvolvimento de um **site com múltiplas páginas utilizando Bootstrap 5**, aplicando conceitos de estruturação, estilização e organização de interfaces web.

O objetivo foi explorar os recursos oferecidos pelo framework Bootstrap, facilitando a construção de layouts organizados e a utilização de componentes visuais no desenvolvimento Front-End.

---

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação das páginas web.
- **CSS3:** Personalização da aparência visual.
- **Bootstrap 5:** Framework utilizado para construção do layout e organização dos componentes.
- **VS Code:** Ambiente de desenvolvimento.
- **GitHub:** Armazenamento e versionamento dos arquivos.

---

## 📊 Resultados e Aprendizados

A atividade proporcionou o estudo e a aplicação de um framework CSS no desenvolvimento de páginas web.

### Principais Aprendizados

- Organização de projetos com múltiplas páginas HTML.
- Introdução ao framework Bootstrap 5.
- Utilização de classes e componentes do Bootstrap.
- Compreensão dos conceitos de layouts responsivos.
- Integração entre HTML, CSS e Bootstrap.
- Organização da estrutura visual de um site.
- Aprimoramento das práticas de desenvolvimento Front-End.

O projeto contribuiu para ampliar meus conhecimentos sobre ferramentas que auxiliam na construção de interfaces web e na organização de projetos com múltiplas páginas.
