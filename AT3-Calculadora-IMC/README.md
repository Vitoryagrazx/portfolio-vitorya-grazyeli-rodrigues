
# 🧮 AT3 - Calculadora de IMC

## 📝 Descrição do Projeto

Este projeto foi desenvolvido na disciplina de **Desenvolvimento Front-End para Web**, do curso de **Análise e Desenvolvimento de Sistemas (ADS)** da Universidade Cidade de São Paulo (UNICID), no 2º semestre de 2026.

A atividade consistiu no desenvolvimento de uma **Calculadora de Índice de Massa Corporal (IMC)**, utilizando HTML, CSS e JavaScript.

O objetivo principal foi aplicar conceitos de programação e interatividade no desenvolvimento de uma página web, permitindo calcular o IMC a partir das informações de peso e altura fornecidas pelo usuário.

---

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação da página e dos campos de entrada.
- **CSS3:** Estilização visual da interface.
- **JavaScript:** Implementação da lógica de cálculo do IMC.
- **VS Code:** Ambiente de desenvolvimento.
- **GitHub:** Armazenamento e organização do projeto.

---

## 📊 Resultados e Aprendizados

A atividade proporcionou a aplicação prática de conceitos fundamentais do desenvolvimento Front-End.

### Principais Aprendizados

- Criação de interfaces utilizando HTML e CSS.
- Utilização do JavaScript para realizar cálculos.
- Manipulação de valores inseridos pelo usuário.
- Aplicação de operações matemáticas na programação.
- Organização e estruturação dos arquivos de um projeto web.
- Identificação e correção de erros durante o desenvolvimento.

O projeto contribuiu para o aprimoramento do raciocínio lógico e para a compreensão da integração entre HTML, CSS e JavaScript.
