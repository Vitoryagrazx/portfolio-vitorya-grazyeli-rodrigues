
# 🌐 AT1 - Linkando Páginas em HTML

## 📝 Descrição do Projeto

Projeto acadêmico desenvolvido na disciplina de **Desenvolvimento Front-End para Web**, do curso de **Análise e Desenvolvimento de Sistemas (ADS)** da Universidade Cidade de São Paulo (UNICID), no 2º semestre de 2026.

A atividade consistiu na criação de um site com cinco páginas HTML interligadas, aplicando conceitos de estruturação de documentos e navegação entre páginas.

O projeto possui as seguintes páginas:

- Página Inicial
- Produtos
- Coleção
- Sobre
- Contato

O objetivo principal foi compreender a utilização de links em HTML, especialmente a tag `<a>` e o atributo `href`, permitindo a navegação entre diferentes páginas do site.

---

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação das páginas e criação de links.
- **CSS3:** Estilização visual das páginas.
- **GitHub:** Armazenamento e organização dos arquivos do projeto.

---

## 📊 Resultados e Aprendizados

A atividade permitiu desenvolver uma estrutura de navegação entre diferentes páginas HTML.

### Principais Aprendizados

- Criação e organização de arquivos HTML.
- Utilização de links internos.
- Aplicação da tag `<a>` e do atributo `href`.
- Organização de imagens e arquivos CSS.
- Estruturação de um projeto web com múltiplas páginas.

O projeto contribuiu para meu aprendizado inicial em desenvolvimento Front-End, especialmente na organização e conexão entre páginas web.
