
# 🚀 AT2 - Deploy de Site

## 📝 Descrição do Projeto

Esta atividade foi desenvolvida na disciplina de **Desenvolvimento Front-End para Web**, do curso de **Análise e Desenvolvimento de Sistemas (ADS)** da Universidade Cidade de São Paulo (UNICID), no 2º semestre de 2026.

O projeto tem como objetivo compreender o processo de publicação de um site na internet, utilizando a plataforma **GitHub Pages** para disponibilizar páginas web diretamente a partir de um repositório.

A atividade aborda a organização dos arquivos de um projeto Front-End, a configuração de hospedagem e a importância de disponibilizar aplicações web para acesso por meio de um endereço público.

### 🎯 Objetivo do Projeto

Aprender a realizar o deploy de um site, compreendendo as etapas necessárias para transformar arquivos desenvolvidos localmente em uma página acessível pela internet.

---

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação das páginas web.
- **CSS3:** Estilização e apresentação visual das páginas, quando aplicável.
- **GitHub:** Armazenamento e organização dos arquivos.
- **GitHub Pages:** Hospedagem e publicação do site.

---

## 📊 Resultados e Aprendizados

A atividade permitiu estudar o processo de publicação de projetos Front-End e a utilização do GitHub como ferramenta de hospedagem.

### Principais Aprendizados

- Organização dos arquivos de um projeto web.
- Criação e gerenciamento de repositórios no GitHub.
- Configuração do GitHub Pages.
- Compreensão do processo de deploy.
- Utilização de links públicos para compartilhar projetos.
- Identificação e correção de possíveis problemas de publicação.

### Importância da Atividade

O deploy é uma etapa importante no desenvolvimento web, pois permite que um projeto deixe de ser acessível apenas no ambiente local e possa ser visualizado por outras pessoas.

Esse conhecimento contribui para a criação de portfólios digitais e a apresentação de projetos acadêmicos e profissionais.
